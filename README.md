## My contribution

I define problems and requirements, organize AI-assisted development, evaluate proposed changes, and examine the evidence behind project decisions. I use AI coding tools as part of that process and distinguish my decisions from generated implementation and independently verified results.

The project stack includes Python, PowerShell, Git, GitHub Actions, Windows tooling, and local model infrastructure. This describes the tools used in the work, not a blanket claim of expert proficiency in every component.

## How I work

- Clear requirements before implementation.
- Explicit permissions for consequential actions.
- Traceable decisions and reviewable changes.
- Honest distinctions between a design goal, an implemented feature, a passing check, and an accepted result.
